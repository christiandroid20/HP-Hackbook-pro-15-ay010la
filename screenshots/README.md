# Capturas y evidencias

Esta carpeta está preparada para evidencias del proyecto; todavía no se han añadido capturas verificadas.

Al añadir una imagen:
- Incluye fecha, versión de macOS y qué función demuestra.
- Recorta números de serie, UUID, correos, nombres de usuario y otra información privada.
- No uses capturas de una EFI de referencia como evidencia de que la EFI del equipo funciona.
- Usa nombres descriptivos, por ejemplo sonid o-hdmi-monterey.png o acerca-de-este-mac-ventura.png.
