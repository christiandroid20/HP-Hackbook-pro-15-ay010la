# Historial de cambios

Los cambios más recientes aparecen primero.

## 2026-10-11 — V2 de documentación y sitio
- Se amplió el README con descripción del proyecto, hardware y advertencias de privacidad.
- Se añadió una página de inicio adaptable con estética pastel retro.
- Se incorporaron guías de hardware, estado original, compatibilidad macOS, Wi-Fi/Bluetooth, trackpad, HDMI/audio y recuperación.
- Se documentó que la EFI real aún está pendiente y que no debe sustituirse por una EFI genérica.

## Estado inicial
La descripción original del repositorio indicaba compatibilidad EFI desde Monterey hasta Ventura.
